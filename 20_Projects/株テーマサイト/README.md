# 株テーマサイト(ニッチテーマ別 株式検索サイト)

## ゴール

「抹茶 上場企業一覧」のような**細かいニッチテーマ別に上場企業を解説する記事**を積み上げたサイトを作る。
参考: https://matcha-techo.com/matcha-guide/matcha-joujo/

## 確定した方針(2026-08-21)

- **静的サイトで作る**。StockWatch連携は見送り([判断の経緯](#stockwatch連携を見送った理由))
- 1記事あたり **8,000〜10,000字**(参考サイトと同等)
- 各記事に **PER・配当利回り・株主優待** を必ず載せる ← 参考サイトにない差別化点
- 記事の型: ①市場規模と構造 → ②〜④バリューチェーン3層で銘柄解説 → ⑤一覧比較表 → ⑥投資判断3ポイント → ⑦まとめ
- テーマ選定基準: **バリューチェーンを3層に割れて、各層に上場企業が2〜4社いること**

## サウナ記事で確立した書き方(2記事目以降も踏襲する)

1. **3層に割る** — 運営層(需要が直撃)/ 設備層(本業の一部)/ グッズ層(ブランド)。
   この分け方は「その銘柄に何を期待できるか」を決めるので、どのテーマでも成立する
2. **数値は基準日を明記して全社分そろえる** — 株価・PER・PBR・配当利回り・時価総額・優待。
   Yahoo!ファイナンス `finance.yahoo.co.jp/quote/<コード>.T` と `/incentive` から取得できる(株探は403で不可)
3. **既存テーマ株リストの誤りを指摘する** — これが最大の差別化になる。サウナ記事では
   コシダカHD(2157)が2025年11月に温浴事業から撤退済みなのに各サイトのテーマ株に残っている件を指摘した
4. **「関係がある」と「業績に効く」を区別する** — 各社の解説で必ずサウナ事業の位置づけを書く

## 執筆時の作業手順

1. テーマのバリューチェーンを3層に分け、各層の候補企業を洗い出す
2. **各社の事業継続を必ず確認する**(撤退・商号変更・非上場化が頻発する)
   - サウナ記事での実例: コシダカHD=温浴撤退済み / だいわ=2026-07-01に大和冷機工業から商号変更
3. Yahoo!ファイナンスから指標と優待を取得(基準日を記録)
4. 記事を執筆 → `記事/NN_テーマ名.html`
5. 出典と免責を末尾に必ず記載する

## StockWatch連携を見送った理由

2026-08-21にデモを作成して検討した結果、ユーザー判断で見送り。検討時に判明した事実は残す:

- **今すぐ出せた**: 空売り残高(60,432件・日次)、アクティビスト報告(789件)、シグナル(275件)
- **出せなかった**: 株価・PER(`price_cache` が0行)、配当利回り(高配当条件を通過した460社のみ保持)
- **最大の障壁**: StockWatchの業種分類は33業種しかなく「サウナ」のような切り口を持たない。
  **テーマ↔銘柄コードの対応表は手で作るしかない**
- 連携の効果は「記事を書き直さなくてもページが古くならない」の1点。記事本数が増えてから再検討する価値はある
- デモ画面: https://claude.ai/code/artifact/ef7477e0-219f-41f9-bd8e-3563311c1295
